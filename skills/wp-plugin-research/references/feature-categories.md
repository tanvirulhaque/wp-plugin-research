# Feature Categories Checklist

Use this list when extracting a competitor's features and when building the Master Feature Inventory. Not every category applies to every plugin — skip the ones that don't. Add niche-specific categories when needed.

1. **Setup & onboarding** — setup wizard, presets/templates, demo data, import/export settings, migration from other plugins
2. **Core function** — the main job the plugin does (e.g. pricing rules, bundles, bookings, shipping rules)
3. **Rules & conditions** — targeting by product, category, tag, user role, customer, cart total, quantity, date/time, location, payment/shipping method
4. **Product-level options** — per-product settings, variable product support, product types supported
5. **Frontend display** — product page, shop/archive pages, cart, mini-cart, checkout, badges, messages, tables, popups
6. **Design & customization** — styling options, templates, shortcodes, blocks, page-builder widgets (Elementor, etc.), custom CSS
7. **Checkout & orders** — order handling, order meta, order statuses, refunds
8. **Customer account** — My Account pages, customer dashboard, saved data
9. **Notifications & emails** — admin/customer emails, email templates, SMS, webhooks
10. **Admin experience** — settings layout, bulk edit, search/filter, list tables, logs
11. **Reports & analytics** — dashboards, revenue impact, usage stats, CSV export
12. **Automation** — scheduling, cron jobs, rules that run automatically
13. **Integrations** — email marketing, CRM, ERP, accounting, payments, shipping, page builders, membership/subscription plugins, other popular WooCommerce extensions
14. **Compatibility** — HPOS, Cart & Checkout Blocks, multisite, WPML/Polylang, multi-currency, caching, themes
15. **Developer tools** — hooks/filters, REST API, WP-CLI, documentation for developers
16. **Access & roles** — user roles/capabilities, shop manager access, B2B/customer groups
17. **Performance** — caching, lazy loading, optimized queries
18. **Security & compliance** — GDPR tools, data export/erase, permission checks
19. **Localization** — translation-ready, RTL support, multi-language content
20. **Support & docs** — documentation, video tutorials, live chat, response time, community
21. **AI / smart features** — suggestions, auto-generated content, predictions (only if present or genuinely useful)
