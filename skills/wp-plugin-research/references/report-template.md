# Research Report Template

(One of 4 deliverables — see SKILL.md Output. Technical detail lives in the Technical Report; the overall decision in the Final Decision Summary.)

Use this order. Keep each section short and simple.

Every section follows the same shape:
- **Bold takeaway line** (the answer)
- Table or 3–5 one-line bullets (the proof)
- → What this means: one line (the decision)

Main report = decision-driving highlights only (top 5s, key numbers). Full lists live in the Research Workbook or the appendix.

```markdown
# [Plugin Idea] — Research Report
Data as of [date] · Labels: Fact / Estimate / Assumption

## 🧭 Decision Page (read this first)
| Block | Content |
|---|---|
| Verdict | GO / MAYBE / NO-GO · Score XX/35 · Confidence H/M/L |
| Why yes | 3 reasons, each with one number |
| Why not | 3 risks, each with one number |
| Key numbers | 5–6 numbers |
| Top 5 opportunities | one line each |
| Your decisions | 2–4 choices + options + my recommendation |
| What would change my mind | 1–3 facts |
| Next step | one action |

## 📊 Opportunity Dashboard
(format from analytics-playbook.md §10) + TAM/SAM/SOM + good signs / red flags

## 1. The Idea
What it does, who it's for, pain removed, keyword list, user types.

## 2. Similar Plugins Found
Count found + top 10 table (plugin, seller, model, installs/sales, rating, last update, ✅/⚠️/❌). Full list → workbook Plugin_Master.

## 3. Shortlist
Deep-research plugins and why each was chosen. Quick-scan plugins with headline features.

## 4. Plugin Cards
One short card per deep-research plugin: key stats, health signals, top features, love/hate, messaging, mini SWOT, weak spot. Full feature list → workbook / appendix.

## 5. Analytics
5.1 Competitor health table
5.2 Market structure
5.3 Demand
5.4 Money (price distribution, sales signals)
5.5 Sentiment & support
5.6 Risk
5.7 Competitor marketing
5.8 Revenue forecast (3 scenarios, years 1–3) + break-even

## 6. Feature Analysis
6.1 Feature inventory (summary: counts by category + key features)
6.2 Feature matrix (key features only; full matrix → workbook Feature_Matrix)
6.3 Feature classification (Must-have / Common Pro / Differentiators / Weak / Gaps)
6.4 Feature demand evidence
6.4b Independent research check
6.5 Pain points (top pains with Review IDs; all → workbook)
6.6 Opportunities (G IDs)
6.7 Benefits (with evidence strength)
6.8 Opportunity scorecard (top 5)

## 7. Proposed Features for Our Plugin
7.1 New & innovative feature ideas (table)
7.2 Final Feature Set (priority + Free/Pro)
7.3 Feature Priority Map (quick wins / big bets / fill-ins / skip)
7.4 MVP feature specs

## 8. Positioning
Positioning map, winning sentence, top 3 selling points, name ideas, tagline.

## 9. Technical Summary
3–5 lines: difficulty, MVP build time, biggest technical risk, our technical edge. Full detail → Technical Report.

## 10. Pricing
Tier table with features + Free vs Pro comparison table.

## 11. Project Plan
Week-by-week MVP plan + feature roadmap by version.

## 12. Launch & Marketing
Feature-based marketing ideas.

## 13. Score
Devil's advocate pre-mortem, scoring table with the number behind each score, total, verdict.

## 14. Validate Before Building
Landing page, feature voting, where to post, message, target number.

## 15. Build Handoff
First 5 build actions + recommended companion dev skills (review before installing).

## Appendix (optional)
Full lists that don't fit the lean main report.

## Limits & Coverage
What couldn't be retrieved, samples, unverified claims, conflicts found.

## Sources
(Full evidence in the Research Workbook: [slug]-research.xlsx)
All links used.
```
